# MSc Data Science Coursework: Notebook Archive

A snapshot (January 2025) of three notebooks from my first year of the MSc in Data Science at the University of Naples Federico II. Each one has a dedicated repository with full documentation, history and teammates' contributions; this repo keeps the final versions together in one place.

| Notebook | Project | Main repository |
|---|---|---|
| `Final_Project_Hardware_and_Software.ipynb` | Student outcome prediction on the Open University Learning Analytics Dataset (OULAD): data merging and EDA | [Hardware-and-software-project](https://github.com/Faiz-Hussain650/Hardware-and-software-project) |
| `Final_project.ipynb` | Extended OULAD modelling: binary pass/fail targets, Random Forest, Decision Tree, GRU/LSTM | [Hardware-and-software-project](https://github.com/Faiz-Hussain650/Hardware-and-software-project) |
| `Working_project_ML_.ipynb` | Weather observations at three Italian airports: cleaning, EDA, ARIMA/SARIMA | [Project_ML-](https://github.com/Faiz-Hussain650/Project_ML-) |

Read the linked repositories for methods, results and known limitations. All notebooks run in Google Colab once the datasets are uploaded to `/content/`.
